## CredVault

[Repository](https://github.com/DavidE008/CredVault)

CredVault is a full-stack credential vault and verification-review platform for academic degrees, transcripts, professional certifications, and other credential records.

**Technology:** Next.js, TypeScript, React, Supabase, Zod, Vercel

### Highlights

- Holder, verifier, and administrator workflows
- Role-based authentication and protected application routes
- Supabase database migrations and row-level security policies
- Public credential-sharing profiles and verification lookup
- JSON, CSV, and print-ready metadata exports
- Validation, automated tests, production builds, and deployment checks
- Security-first approach that keeps raw document uploads disabled until secure storage controls are complete

## SweeperLab

[Repository](https://github.com/DavidE008/SweeperLab)

SweeperLab is a mobile-first Minesweeper trainer designed around playable game modes, persistent progress, hints, and post-match learning.

**Technology:** React Native, Expo, TypeScript, Jest, AsyncStorage

### Highlights

- Beginner, Intermediate, Expert, and bounded Custom boards
- First-click-safe mine placement
- Reveal, flag, chord, score, and win/loss game logic
- Timer, mine counter, progress display, match history, and coaching tools
- Zoom and free-pan support for larger boards
- Local persistence with AsyncStorage
- Type checking, automated tests, and continuous integration
